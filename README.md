# InstaChat Browser

A browser-based Instagram chat viewer. Upload your Instagram data export ZIP and browse your conversations with a familiar chat UI.

## Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:9002](http://localhost:9002) in your browser.

## Features

-   View Instagram chat history from ZIP export
-   Search conversations and messages
-   View photos, videos, stickers, and voice messages
-   All data is processed locally in the browser — nothing is uploaded
